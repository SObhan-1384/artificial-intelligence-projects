# Artificial Intelligence Course Projects

A collection of selected projects developed as part of the **Artificial Intelligence** course at **Sharif University of Technology**.

The repository covers fundamental topics in classical AI, probabilistic reasoning, machine learning, sequential decision making, and reinforcement learning. Several algorithms are implemented from scratch to better understand their underlying mechanics.

## Projects

| Project | Topics |
|---|---|
| 🎮 **Adversarial Search & Tic-Tac-Toe** | Minimax, Alpha-Beta Pruning, Move Ordering |
| 🧩 **Nonogram as a CSP** | Backtracking, Forward Checking, MRV, AC-3 |
| 🎲 **Bayesian Networks** | D-Separation, CPT Estimation, Variable Elimination, MAP Inference, Value of Information |
| 🧬 **Hidden Markov Models** | HMMs, Parameter Estimation, Forward Algorithm, DNA Sequences |
| 📈 **Machine Learning from Scratch** | Linear Regression, Perceptron, Logistic Regression, Multiclass Classification, Neural Networks |
| 🌳 **Decision Trees & Random Forests** | Entropy, Gini Impurity, Information Gain, Bootstrap Sampling |
| 🔄 **Markov Decision Processes** | Policy Evaluation, Policy Iteration, Value Iteration |
| 🚕 **Reinforcement Learning** | Q-Learning, SARSA, ε-Greedy Exploration, Gymnasium Taxi |

## Highlights

- Implemented several classical AI and machine-learning algorithms from scratch.
- Compared different search and optimization strategies experimentally.
- Applied probabilistic graphical models to inference problems.
- Implemented decision trees and random forests without relying on their high-level library implementations.
- Explored dynamic programming methods for Markov Decision Processes.
- Compared Q-Learning and SARSA under different exploration strategies.
